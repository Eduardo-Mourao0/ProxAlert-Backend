# ProxAlert Backend

Backend do ProxAlert, um aplicativo de alarme por proximidade geográfica.

O projeto tem como objetivo permitir que usuários criem alarmes baseados em localização, recebendo notificações ao se aproximarem de um destino definido. A aplicação também prevê um modo terceiro, onde é possível gerar um link temporário para que outra pessoa compartilhe sua localização sem precisar criar conta ou instalar o app.

## Tecnologias

- NestJS
- TypeScript
- Prisma ORM
- PostgreSQL
- PostGIS
- Docker

## Objetivo

Construir uma API organizada, escalável e preparada para evoluir com regras de negócio relacionadas a usuários, alarmes, localização, planos e compartilhamento temporário.
